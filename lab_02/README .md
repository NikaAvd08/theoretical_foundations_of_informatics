# Система анализа и обработки заказов
## Консольное Python-приложение для считывания, валидации, фильтрации и анализа данных о заказах из текстового файла, а также формирования итогового отчета.

## Описание проекта
### Программа выполняет следующие задачи:
- Чтение и валидация данных: считывает файл orders.txt и проверяет корректность данных 
- Интерактивное консольное меню: позволяет пользователю фильтровать, сортировать и просматривать заказы прямо в терминале.  
- Генерация отчета: формирует подробный итоговый файл orders_report.txt с общей статистикой, списками заказов и зарегистрированными ошибками входных данных.  

### Валидация входных данных
### При загрузке файла orders.txt проверяются следующие условия:  
- Формат: строка содержит ровно 6 полей, разделенных точкой с запятой ; (ID; Покупатель; Категория; Количество; Цена; Статус).  
- ID заказа: положительное целое число, уникальное в пределах файла.  
- Обязательные поля: имя покупателя и категория товара не должны быть пустыми.  
- Количество: положительное целое число.  
- Цена: положительное число.  
- Статус заказа: должен входить в список допустимых статусов (новый, в обработке, выполнен, отменён).  
- Все строки, не прошедшие валидацию, помещаются в список ошибок и выводится соответствующее предупреждение в отчете.  


## Структура проекта

lab_02

├── main.py              # Основной скрипт программы

├── orders.txt           # Входной файл с данными о заказах

└── orders_report.txt    # Автоматически создаваемый отчет с результатами

### Формат файла orders.txt
Файл должен быть сохранен в кодировке UTF-8 и содержать записи в следующем формате:  

101;Иван Иванов;Электроника;2;15000.00;выполнен

102;Анна Смирнова;Одежда;1;3500.50;в обработке

103;Петр Петров;Электроника;1;50000.00;новый


## Инструкция по запуску
### 1.Требования:
Установленный интерпретатор Python 3.x.

### 2.Подготовка
Поместить файлы main.py и orders.txt в одну папку.

### 3.Запуск
Выполните команду в терминале:

python main.py


## Функционал меню
После запуска программы в консоли появится интерактивное меню:  
- 1. Показать все заказы: вывод всех корректно распознанных заказов.  
- 2. Показать заказы по убыванию стоимости: сортировка заказов по общим затратам.  
- 3. Показать заказы по категориям: сортировка по категориям.  
- 4. Найти заказы по статусу: поиск указанному статусу. 
- 5. Найти заказы по категории: поиск по названию категории.  
- 6. Найти заказы покупателя: поиск по имени клиента.  
- 7. Показать крупные заказы: вывод заказов, стоимость которых превышает или равна 5000.  
- 8. Показать статистику: вывод сводки по категориям, статусам, общему количеству и выручке.  
- 9. Сохранить отчёт: генерация текстового файла orders_report.txt с подробным анализом.  
- 0. Завершить программу: выход из приложения.  


## Содержимое файла orders_report.txt
### При выборе пункта 9 программа формирует текстовый файл orders_report.txt со следующими разделами:  
- Количество корректных записей.  
- Количество некорректных записей.  
- Перечень уникальных категорий.  
- Заказы по убыванию стоимости.  
- Перечень крупных заказов (от 5000).  
- Общие показатели (количество заказов, стоимость, выручка по выполненным, средний чек, самый дорогой заказ, лучший покупатель).  
- Статистика по категориям.  
- Статистика по статусам.  
- Список ошибок входных данных (с указанием номеров строк).
